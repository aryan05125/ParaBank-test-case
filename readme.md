# ParaBank Banking Application Manual Testing Project

## Project Overview

This project focuses on Manual Testing of the ParaBank Banking Application.

The objective of this project was to perform Functional Testing, Validation Testing, Positive Testing, Negative Testing, and Defect Reporting on banking modules.

## Website Under Test

Website:
https://parabank.parasoft.com/parabank/index.htm

* Mandatory Field Validation

* Error Handling

### Login

* Login Functionality Verification

* Test Cases Designed

## Bugs Identified

### BUG_001

Internal server error displayed when First Name field is left empty during registration.

### BUG_002

Registered user is unable to login with valid credentials.

## Blocking Defect

The Login functionality failed for a registered user.

Due to this issue, the following modules could not be executed:

* Open New Account
* Transfer Funds
* Bill Pay

Status: Blocked
